# 塔罗秘境 · Arcana

一款可本地离线游玩的塔罗牌抽牌小游戏，带完整的 78 张牌面图片资源与鼠标运动特效。

## 快速开始
- 一键桌面窗口：双击 `启动塔罗秘境.bat`（以独立无边框窗口打开，优先使用 Edge，其次 Chrome）。
- 或直接用浏览器打开 `index.html`。
- 均无需安装依赖、无需联网。

> 说明：启动脚本会解析自身所在目录生成 `file://` 地址，因此请保持整个项目文件夹路径不含空格；含空格时请直接用浏览器打开 `index.html`。

## 玩法
1. 选择牌阵：**单张牌阵**、**三牌阵（过去 / 现在 / 未来）** 或 **凯尔特十字（10 张）**。
2. 点击 **洗牌**，再点击 **抽牌**（或直接点击中央牌堆）。
3. 点击翻开的牌背，卡牌会以 3D 动画翻面，并给出正位 / 逆位解读。

## 特效
- 鼠标移动会洒落金色星光粒子，并拖动柔和光晕与光环。
- 背景星海与星云随鼠标产生视差。
- 卡牌会随鼠标位置产生 3D 倾斜与高光。
- 抽牌、翻牌时触发粒子爆发。

## 图片资源
- `images/card-back.svg`：卡背。
- `images/cards/*.svg`：完整 78 张牌（22 张大阿卡纳 + 56 张小阿卡纳，含权杖 / 圣杯 / 宝剑 / 星币四花色与宫廷牌）。
- 资源为 SVG 矢量格式，缩放无损。如需重新生成：`node tools/generate-cards.js`。

## 目录
- `index.html` 页面入口
- `启动塔罗秘境.bat` 一键桌面窗口启动器
- `css/style.css` 样式与动画
- `js/deck.js` 卡牌数据与解读
- `js/effects.js` 鼠标粒子 / 光晕 / 视差 / 倾斜特效
- `js/main.js` 游戏流程（含三种牌阵）
- `tools/generate-cards.js` 卡牌 SVG 生成脚本
